# Observed source: Olist seller footprint

The reference CSVs were computed from the public Olist sellers table:
https://raw.githubusercontent.com/spdrio/Brazilian-E-Commerce-Public-Dataset-by-Olist/master/files/olist_sellers_dataset.csv

Original publisher: Olist, https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce, source licence CC BY-NC-SA 4.0.

The dataset contains 3,095 distinct seller IDs and 23 Brazilian state codes. The seller state counts sum to 3,095; São Paulo contains 1,849. The city profile contains the top 20 raw city/state strings, not verified legal addresses.

These are actual source-derived aggregates, not transaction-level delivery data. They cannot be interpreted as seller delivery performance, sales volume or purchasing reliability.
